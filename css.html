02 CSS

Dale estilo a tus páginas

CSS permite modificar colores, tamaños, posiciones, espacios y mucho más

¿Qué es CSS?

CSS significa Cascading Style Sheets. Se utiliza para controlar la apariencia visual de los documentos HTML 

body {
    background: #111;
    color: white;
}

h1 {
    font-size: 40px;
}

Conceptos básicos

  • Selectores
  • Colores
  • Tipografías
  • Margen
  • Padding
  • Flexbox
  • Media Queries

Responsive Design

Una página responsive adapta su contenido automáticamente a diferentes tamaños de pantalla.

Cambia el tamaño de la ventana para observar cómo se adapta el contenido.
